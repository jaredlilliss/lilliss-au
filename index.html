About

Two kinds of work,
one set of habits

The health platform is a polling loop feeding an append-only PostgreSQL time series. Its privacy posture is set at the schema level — there is no column for personal or health information, so none can be collected by mistake rather than none being collected by policy. Nothing is ever updated in place either: a reading that turns out to be wrong is corrected by a later row, not by editing the record of what was published at the time.

The site work is the same instinct. Every build here is a single self-contained HTML file — no framework, no build step, no tracker, fonts served from the same domain — because a page that depends on four services is a page with four ways to stop working.

The field work keeps it honest. When a venue's tills stop mid-service the fix has to hold, and it has to be written down, because the next person on that site inherits whatever I leave behind. See the build →
